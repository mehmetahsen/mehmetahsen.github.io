How to use

What you need

  • Chrome, Edge or another Chromium-based browser on Windows, macOS, Linux, ChromeOS or Android. Firefox, Safari and all browsers on iPhone and iPad cannot talk to USB devices.
  • The SAM-Funktrainer receiver plugged into this computer, the target unit powered, and the gun sensor charged and switched on.

One-time setup

  • Windows: the receiver needs Windows' generic WinUSB driver.
    1. Download Zadig and start it.
    2. Choose Options → List All Devices, then pick SAM-Funktrainer from the list (USB ID 0ADC 0005).
    3. Make sure the target driver box says WinUSB and click Replace Driver (or Install Driver).
    4. Unplug the receiver and plug it in again, then reload this page.
    The old Knestel software will no longer find the receiver on this computer. To undo, open Device Manager, uninstall the SAM-Funktrainer device with "delete the driver", and replug it.
  • Linux: allow your user to access the receiver, then replug it:
    echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="0adc", ATTR{idProduct}=="0005", MODE="0660", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/70-sam-funktrainer.rules
    Chromium installed as a snap also needs sudo snap connect chromium:raw-usb.
  • macOS, ChromeOS, Android: nothing to do. On Android, connect the receiver with a USB-OTG adapter.

Shooting

  1. Click Connect and choose the SAM-Funktrainer. The line under the title tells you what to fix if something is missing.
  2. Below about 6 m set the switch on the target unit to "near", further away to "far".
  3. Choose your target type. To shoot at paper, print a target at the right size under Targets and printing.
  4. If the dot moves the wrong way when you move the gun, change Mount angle in steps of 90°.
  5. Fire a few shots at the centre and click Centre on shots; this is the quick adjustment.
  6. Click a shot's ring value to see its aim trace and diagrams.

Your data

Shots are saved automatically in this browser only. Use JSON under Saved sessions to keep a copy or move it to another computer.

If it does not work

  • The receiver is not in the list: on Windows, install the WinUSB driver as above; on Linux, add the rule above and replug.
  • "Access denied" or "unable to claim": another program or browser tab is using the receiver. Close it, replug, try again.
  • The sensor does not answer: switch it on and check its battery. If it still does not answer, use Search for the sensor under Device settings.

    Device settings

    Warning: these functions change settings stored inside the receiver and the gun sensor. They follow what the original software does, but this project has not tested them on real hardware. A wrong value can leave the sensor unreachable (radio channel) or the system unusable until the old values are written back, and no factory reset is known. The settings are backed up in this browser automatically when they are read and again right before every write. Export a backup to a file before you start.

    Shot detection sensitivity

    How weak a trigger click may be and still count as a shot. Lower it if loading the gun triggers shots. The original software offers 0–100 %, default 85.

    Radio channel

    Receiver and sensor must use the same channel. Change it only to avoid interference from another trainer nearby.

    Calibration

    Print the calibration sheet ("Targets and printing") and fix it on the target unit. Aim at each mark in turn, hold still, and press Capture or fire a shot. Keep "New formula" and "Mount angle" unchanged afterwards.
